Основы дискретно-событийного моделирования (M/M/1 & M/M/n)

О проекте

Базовая реализация одноканальной и многоканальной систем массового обслуживания. Проект демонстрирует фундаментальные навыки работы с Process Modeling Library в AnyLogic.
Техническая реализация
Генерация трафика: Использование блока Source с экспоненциальным законом распределения времени прибытия.
Обслуживание: Настройка пропускной способности через блоки Queue (очереди) и Delay (задержки обслуживания).
Базовая статистика: Применение блоков TimeMeasureStart и TimeMeasureEnd для фиксации времени пребывания заявки в системе.
