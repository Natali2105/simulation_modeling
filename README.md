Это дополнение к моему портфолио. Здесь собраны проекты по имитационному моделированию сложных систем, очередей и городского трафика.

Стек технологий и навыки:

Инструмент: AnyLogic 8 (Java)

Подходы: Дискретно-событийное (Process Modeling), Агентное моделирование (Agent Based), Системная динамика.

Библиотеки: Process Modeling Library, Road Traffic Library.

Специфика: Разработка Statecharts (диаграмм состояний), интеграция 2D/3D анимации, сбор статистики (гистограммы, Time Plots), применение закона Литтла, оптимизация "узких мест" (bottlenecks).

Список проектов:

01 и 02 — Базовые дискретно-событийные СМО.

03 — Модель роевой обработки (Pooled Resources) с математической верификацией.

04 — Гибридная архитектура (интеграция Process Flow и Агентных Statecharts).

05_Smart_City_Parking_Twin — Транспортная модель района с умными светофорами и нестационарным трафиком.
