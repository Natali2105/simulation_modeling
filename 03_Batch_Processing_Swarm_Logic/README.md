Моделирование пакетного поступления и роевой обработки

О проекте
Имитационная модель СМО, в которой заявки поступают динамическими группами (пакетами) случайного размера. Ключевая особенность — алгоритм обслуживания «все как один» (Pooled Resource Allocation): при поступлении пакета на его обработку монопольно выделяются сразу все доступные каналы.

Техническая реализация
Кастомная генерация: Блок Source динамически создает массив агентов (от 1 до d), присваивая им ID группы и время поступления.
Логика обслуживания: Блок Delay настроен на синхронную обработку. Длительность операционного цикла рассчитывается динамически.
Верификация: Система в реальном времени сравнивает экспериментальные значения с теоретическими, рассчитанными по формулам марковских цепей (вероятность простоя P_0, закон Литтла). Сходимость данных доказана (погрешность <10%).
