Моделирование СМО с маршрутизацией и отказами обслуживания

О проекте

Усложненная модель системы массового обслуживания, включающая алгоритмы принятия решений и ограничения по вместимости. Проект имитирует реальные бизнес-процессы с потерями клиентов из-за перегрузки системы.


Техническая реализация

Маршрутизация (Routing): Использование блоков SelectOutput для разделения потоков заявок на основе вероятностей или заданных условий.

Система с отказами: Ограничение длины очереди (Capacity) в блоке Queue. Реализация альтернативного сценария: если очередь заполнена, заявка перенаправляется в блок Sink (учет потерянной прибыли/отказов).

Сбор метрик: Расчет доли отказов (Probability of Rejection) и коэффициента использования ресурсов (Utilization).
