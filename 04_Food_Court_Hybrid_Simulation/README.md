Моделирование ресторанного дворика (Гибридная многоканальная СМО)

О проекте

Разработана имитационная модель фуд-корта (6 независимых пунктов обслуживания) для анализа пропускной способности и уровня отказов при ограниченном времени ожидания. Проект демонстрирует применение гибридного подхода: интеграцию дискретно-событийного конвейера с агентной логикой, управляемой конечными автоматами (Statecharts).

Техническая реализация

Маршрутизация агентов: Реализован интеллектуальный алгоритм выбора наименее загруженной очереди (балансировщик нагрузки).

Агентный подход (Statecharts): Вместо классического удаления заявок из очередей по таймауту, логика инкапсулирована внутрь каждого агента (клиента). Диаграмма состояний агента (Choosing, Waiting, Serving, LeftUnserved) напрямую принимает сигналы от блоков Queue и Delay через методы fireEvent().

Устранение коллизий: Использование стейтчартов позволило избавиться от архитектурных багов стандартной библиотеки при извлечении агента из середины очереди (Preemption).

Сбор метрик: Автоматический расчет вероятности простоя системы (P_0 ≈ 0.001), загрузки каналов (Utilization) и средних времен ожидания с использованием встроенных статистических объектов.


Бизнес-результаты моделирования

Модель была протестирована под нагрузкой (прогон более 1000 минут). Система была выведена в стационарный режим (насыщение). При данных параметрах (20 кассиров суммарно) целевое время ожидания стабилизировано на отметке 7.00 минут, что подтвердило математическую корректность заложенной логики.
