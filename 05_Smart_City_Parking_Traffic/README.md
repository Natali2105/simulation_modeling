Интеллектуальная парковочная система (Smart City Traffic Model)

О проекте
Создан цифровой двойник (Digital Twin) городского района для решения проблемы "блуждающего трафика". Модель оценивает эффективность системы умного информирования (IoT-табло) и пропускную способность трех типов парковок (Бесплатная, Платная, EV-зона) в условиях неравномерной нагрузки (часы пик).

Техническая реализация
Road Traffic Library: Спроектирована топология дорожной сети. Для предотвращения эффекта "глухого затора" (Gridlock) въезды на парковки реализованы в виде односторонних кольцевых маршрутов, разводящих встречные потоки.
Умные светофоры (Statecharts): Разработана кастомная логика контроля въезда. Стоп-линии управляются конечными автоматами (RedPhase / GreenPhase). Автомат динамически переключает фазы в зависимости от наличия свободных мест (nFree() > 0), предотвращая блокировку транзитных магистралей.
Нестационарный пуассоновский поток: Интенсивность генерации автомобилей (CarSource) регулируется объектом Schedule, точно имитируя утренние и вечерние пики трафика.
Поведенческие паттерны водителей: Внедрена логика ограниченного терпения. Агент ожидает перед парковкой не более 5 минут. При таймауте срабатывает вероятностное ветвление: 60% перенаправляются на альтернативную платную зону, 40% покидают район (Отказ).

Бизнес-результаты моделирования
Эксперимент (5 часов модельного времени) показал, что текущая инфраструктура (95 мест) не справляется с утренним пиком (коэффициент успешности ~35%).
Выявлен дефицит эко-мест: 30.8% владельцев электромобилей не смогли зарядить авто. Платная парковка генерирует стабильный доход, но требует введения динамического тарифообразования для повышения оборачиваемости (снижения среднего времени стоянки с текущих 127 мин).
